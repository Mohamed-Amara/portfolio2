# Mohamed Amara — Portfolio

A single-page React, TypeScript, Vite and Tailwind portfolio focused on engineering and technical commercial opportunities.

## Local development

```bash
npm install
npm run dev
```

Use `npm run lint` and `npm run build` before deployment.

## Content notes
